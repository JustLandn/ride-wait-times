# ride-wait-times

## Virtual environment

Create a virtual environment:

```bash
python3 -m venv venv
```

Activate it:

```bash
# macOS/Linux
source venv/bin/activate

# Windows
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Deactivate when done:

```bash
deactivate
```
